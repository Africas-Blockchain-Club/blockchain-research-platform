## Phase 0: The Blockchain

### 0.1 What It Is For

A ledger built for payments and exchanging currencies quickly and cheaply, with a decentralised exchange built into the ledger itself.

| Question | Answer |
|---|---|
| Launched | June 2012 |
| How it reaches agreement | The XRP Ledger Consensus Protocol. There is no mining and no staking: validators agree on each ledger version, and each server chooses the validators it trusts (its Unique Node List). |
| What can be built on it | Built-in features rather than general smart contracts: payments, issued tokens, a native decentralised exchange, escrow and payment channels. |
| What the native asset does | XRP is the native asset and a bridge currency. 100 billion XRP were created at launch and no more can be made; the small fee on every transaction is destroyed, so the supply only shrinks. |
| Main uses today | Cross-border payments, Currency exchange on the built-in exchange, Issued tokens and stablecoins, Tokenised real-world assets |

> **Reading this table:** the consensus method decides who can add blocks and what an attacker would need to control. The native asset's role tells you why anyone needs to hold it.

Check these facts at the source: https://xrpl.org/docs, https://xrpl.org/docs/concepts/consensus-protocol.

## Phase 1.5: Exchange Pool Maths

Main pool: raydium on solana, found by ticker search only; the contract could not be confirmed.

Most decentralised exchanges price a token with the constant product formula: x multiplied by y equals k. x is the number of tokens in the pool, y is the number of the paired token, and k stays fixed. When someone buys tokens out of the pool, x falls, so y has to rise to keep k the same, and the price goes up. Selling does the opposite.
